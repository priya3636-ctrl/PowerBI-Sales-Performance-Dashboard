# 📊 Power BI Sales Performance Dashboard

An interactive Power BI dashboard built to analyze sales performance across products, categories, and regions.

## 🎯 Project Overview

This project demonstrates how raw sales data can be transformed into an interactive business intelligence dashboard using Power BI.

The dashboard provides insights into:

- Total Sales
- Total Profit
- Total Cost
- Total Orders
- Total Quantity
- Sales by Product
- Sales by Category
- Profit by Region
- Sales Trends
- Detailed Sales Analysis

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel
- Data Modeling
- Data Visualization

## 🔄 Project Workflow

Raw Excel Data  
↓  
Power Query – Data Preparation  
↓  
Data Modeling & Relationships  
↓  
DAX Measures  
↓  
Interactive Visualizations  
↓  
Sales Performance Dashboard

## 📈 Dashboard Features

- KPI cards for key business metrics
- Product-wise sales analysis
- Category-wise sales analysis
- Region-wise profit analysis
- Sales trend analysis
- Interactive Region, Category and Product slicers
- Detailed sales table
- Interactive filtering
